# Requisitos
## Actores
Administrador, cajero/atención, cocina y propietario.
## Funcionales
RF-01 autenticación; RF-02 autorización por roles; RF-03 consulta de productos; RF-04 administración de productos; RF-05 registro de pedidos y detalles; RF-06 precio histórico; RF-07 historial de estados; RF-08 pagos parciales sin sobrepago; RF-09 entrega únicamente con pedido listo y pagado; RF-10 historial de entregas; RF-11 incidencias; RF-12 reportes; RF-13 auditoría.
## No funcionales
Contraseñas hasheadas, validación de entradas, integridad referencial, secretos fuera del repositorio, API REST, interfaz adaptable.
