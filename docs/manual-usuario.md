# Manual de usuario
1. Inicie sesión con sus credenciales.
2. Menú: consulte los productos. Administrador puede crear producto (la categoría debe existir en la base de datos).
3. Pedidos: registre pedido indicando ID del producto y cantidad; avance los estados con el selector.
4. Cocina: visualice y avance los pedidos en preparación.
5. Pagos: registre pago para un pedido abierto; no se permiten pagos mayores al saldo.
6. Incidencias: registre problemas vinculados a un pedido.
7. Reportes/Auditoría: disponibles para roles autorizados.
8. Cierre sesión al terminar.
